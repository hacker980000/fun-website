Social AI Assistant Pro — Privacy & Data Disclosure

এই extension-এর উদ্দেশ্য Facebook, Messenger এবং WhatsApp Web-এ ব্যবহারকারীর অনুরোধে AI-assisted comment এবং message draft তৈরি করা।

Extension স্বয়ংক্রিয়ভাবে message পাঠায় না। Generated text composer-এ draft হিসেবে বসে এবং final send ব্যবহারকারী নিজে করেন।

AI request-এ কী পাঠানো হতে পারে

  • আপনি যে post-এ AI comment চান তার প্রাসঙ্গিক caption/text।
  • Media analysis চালু থাকলে post-এর relevant image URL এবং সম্ভব হলে visible video frame বা thumbnail।
  • Inbox-এর ক্ষেত্রে কোনো পুরোনো conversation প্রথমবার AI ব্যবহার করলে বর্তমানে browser DOM-এ load থাকা শেষ 10 অথবা 30টি recipient/OTHER message এবং কথোপকথন বুঝতে প্রয়োজনীয় কাছাকাছি SELF messages।
  • একই conversation-এর পরবর্তী AI reply তৈরির সময় পুরোনো raw history আবার পাঠানো হয় না।
  • প্রথম analysis-এর compact conversation memory এবং নতুন recipient message ব্যবহার করে পরবর্তী reply তৈরি করা হয়।
  • Popup-এ দেওয়া custom style instructions।

তথ্য কোথায় যায়

AI generation request https://openrouter.ai/ API-তে পাঠানো হয়।

OpenRouter নির্বাচিত upstream AI provider-এর মাধ্যমে request process করতে পারে। OpenRouter এবং সংশ্লিষ্ট provider-এর নিজস্ব privacy এবং data-retention policies প্রযোজ্য হতে পারে।

API key

OpenRouter API key Chrome extension-এর storage.local -এ সংরক্ষিত হয়।

Extension service worker storage access-কে TRUSTED_CONTEXTS -এ সীমাবদ্ধ করার চেষ্টা করে। Facebook/Messenger/WhatsApp content script সরাসরি API key পড়ে না।

OpenRouter API request service worker থেকেই করা হয়।

Inbox Conversation Memory

Extension নিজস্ব কোনো server-এ conversation archive তৈরি করে না।

কোনো পুরোনো Inbox প্রথমবার AI দ্বারা analyse হলে একটি compact conversation summary chrome.storage.session -এ রাখা হয়।

এর উদ্দেশ্য হলো একই পুরোনো 10 বা 30টি recipient message প্রতিবার পুনরায় AI দিয়ে analyse না করা।

একই conversation-এর পরবর্তী reply-এ cached memory এবং নতুন recipient message ব্যবহার করা হয়।

Session memory browser session-এর জন্য ব্যবহৃত হয় এবং popup-এর Clear Inbox Session Memory button দিয়েও clear করা যায়।

Photo ও Video Analysis

Facebook-এর image URL AI provider-এর কাছে সবসময় accessible নাও হতে পারে।

Facebook video অনেক সময় private বা blob stream হওয়ায় extension পুরো video upload করার পরিবর্তে visible frame বা thumbnail capture করার চেষ্টা করে।

Visual analysis সম্ভব না হলে text-only fallback ব্যবহার করা হতে পারে।

Generated Content

Generated text একটি AI draft। গুরুত্বপূর্ণ, ব্যক্তিগত, রাজনৈতিক বা সংবেদনশীল বিষয়ে পাঠানোর আগে ব্যবহারকারীকে text নিজে যাচাই করা উচিত।

Flirty mode-কে respectful, non-explicit এবং non-coercive ভাষা তৈরির জন্য নির্দেশ দেওয়া হয়েছে।

User Control

Popup থেকে media analysis বন্ধ করা যায়, draft preservation পরিবর্তন করা যায়, Inbox history 10 বা 30 recipient message নির্বাচন করা যায় এবং session Inbox memory clear করা যায়।

Privacy/Data consent না দিলে AI generation block থাকবে।
